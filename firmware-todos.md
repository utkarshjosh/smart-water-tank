
Goal: build a fresh, modern, iOS-like, Gluestack-based cross-platform design system for the IoT smart household water tank app.

Important rules:

Ignore the existing UI/design completely.
Do not copy Tailwind, shadcn, current screens, old colors, old spacing, or old component patterns.
Use existing docs, plans, and firmware only to understand the product domain.
Create a new clean fresh-design/design folder.
Build reusable Gluestack-based primitives first.
Then build smart water product components.
Then build showcase/mock screens.
Use TypeScript.
Use design tokens, not random hardcoded styling.
Keep React Native / Expo compatibility.
Avoid unnecessary dependencies.
Do not break existing app routes.
Add a safe optional showcase/dev screen if routing is needed.
